Доступ власника

Ключ використовується лише для запитів до GitHub. Він не зберігається на сайті чи в браузері. Не надсилай його в чат.

Де взяти ключ?
  1. Відкрий створення ключа GitHub ↗.
  2. Назва: onmisto ads. Обери термін дії.
  3. Repository access → Only select repositories → onmisto.
  4. Repository permissions → Contents → Read and write. Інших дозволів не потрібно.
  5. Натисни Generate token, скопіюй ключ і встав вище.
